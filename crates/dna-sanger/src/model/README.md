# Sanger model

Owns canonical Sanger evidence:
- `sanger`: the chromatogram;
- `basecalls`;
- `signal`: locus evidence, integrity, noisy regions, and the short-read
  rejection;
- `locus_evidence`;
- `callability`;
- `quality`;
- `attachment`: the Sanger evidence that reports join to core records.

See [dna-sanger](../README.md).
