# The sources each cached stage of the evaluation harness depends on.
#
# The build script records a stage's code identity from them: the git object
# id of every listed path at the commit, or nothing when one differs from it.
# tools/python/scripts/validate_module_layers.py checks the lists are closed:
# every module a listed source uses, every module file above it, and every
# workspace crate a listed crate depends on, is listed.
#
#   path            a file or directory on the stage's path;
#   path: a, b      a file on the stage's path for items a and b only: listed
#                   whole, and what those items use (their definitions and
#                   impl blocks, through the file's `use` bindings too) is
#                   followed, but not what its other items use;
#   !path           used by a listed source, but not on the stage's path: the
#                   check fails when nothing listed uses it.
#
# Every stage lists the build's own inputs: Cargo.lock, Cargo.toml, and
# rust-toolchain.toml, and this file, so editing a list is a new identity.
