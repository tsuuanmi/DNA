# Known Limitations

These are current interpretation/validation boundaries, not future promises.

- A single chromatogram does not establish genotype, quantitative heteroplasmy, phase, contamination, pathogenicity, or clinical significance.
- Rolling SNR and relative quality are observational/relative measures, not calibrated Phred error probabilities.
- Read callability detects where a read's signal stops being one ladder and masks it; it does not recover the sequence behind a phase shift, and a slipped population above one half flips the primary inside a run with no in-run signature, so only cross-strand disagreement at sample scope can reveal it. Its `dephased` label means that shadows of neighbouring calls explain the double peaks; it does not separate slippage from a ladder smeared by one call, and dinucleotide slippage, whose shadows lie two calls away, is labelled `mixed`. A masked call supports no variant even when its primary call is right, and a variant needs `read_end_margin` informative calls between it and an uninformative end, so a difference right where a read dephases is reported only from a strand that reads it in phase; only the length of a run the read bounds is exempt where the read loses phase right after a repeat run (ADR-0076). When several length populations of similar size meet at a poly-C run, no strand reads the run length, and length insertions such as 309.1C are not reported ([phase-recovery research](../research/phase-recovery/README.md)). A run-length edit whose run end a read does not resolve is excluded (`run_boundary`, ADR-0071), A masked repeat stretch whose calls spell the reference's runs is re-expressed as one length edit per run (ADR-0072), so a read that reads the run lengths before dephasing reports them; a read that loses the anchor base among several length populations still reports none.
- A read's first calls do not support variants, so positions right after the primer can stay uncovered. On the development panel, 10–15 % of HVS-II forward reads place their first aligned or first trusted call past position 73. These reads cluster by run batch. In those samples `73G` is reported only if the reverse read's far end shows it. Rescuing such calls would bring in errors:
  - for non-reference calls within 0–5 calls of the trim start, precision is 0.52;
  - in weak read-start segments before the trim, it is 0.02.

  Covering these positions is a matter of primer placement or run quality control in the laboratory, not of a calling rule.
- Mixed or secondary signal remains evidence; it is not automatically biological heteroplasmy.
- Unresolved evidence remains unresolved rather than being forced into a definitive biological claim.
- The sample consensus (`dna consensus`, ADR-0073, ADR-0074) writes `N` where no read observes a position or run cleanly.
  - **Run lengths that no read shows.** A run whose two ends no single read shows takes the reference frame between the ends that reads locate (`reference_frame`), or the in-phase length before a read loses phase (`phase_loss`). Both are labelled in `sites[].runs` but not in the FASTA, and `dna call` of the consensus document leaves such a run's 3' end, where its length change is written, not callable (SRS-VAR-021).
  - **Length-heteroplasmic tracts.** In a tract such as HVS-I 16184–16193 with `16189C`, the length is therefore a frame or an estimate, never a measurement.
  - **Dominant HVS-I lengths.** A dominant HVS-I length that a read does show (`anchored_end`) is still reported as a length change, although reviewers by convention do not record it.
  - **Unread runs.** A run that no read reads stays `N`, so most remaining misses are HVS-II length calls.
  - **Ties.** One read against one read takes the reference and is marked `contested`.
  - **Point heteroplasmy** is never written as an IUPAC code.
  - **Run lengths lost between consensus and call.** Before ADR-0078, `SampleAnalysis::call` re-read the consensus FASTA. It now calls the consensus's decided edits (SRS-VAR-021), so no re-alignment moves them; a length whose run bound is `N` is still excluded by the record rules (ADR-0071). The account below describes the former path. When the consensus decides a run's length (`in_phase`) but writes `N` at a bound it could not resolve as a base, that `N` leaves the run unbounded for `call`, which excludes the length change (`run_boundary`). On the development panel this drops `315.1C` in 8 samples (7 of them discordant) and a `309` insertion in 22. The same re-alignment used to move an AC-repeat deletion that the consensus decides at `523–524` beside unresolved bases at `513–516`, writing `513DEL 514DEL`; a deletion beside an `N` of a consensus record now takes the 3'-most placement (SRS-ALN-017), and one still beside an `N` is not reported (`unresolved_flank`, SRS-VAR-018). Fixing this requires a decision on the interface: [PROP-0006](../proposals/0006-call-consensus-decisions.md) proposes that `call` reads the consensus's decisions directly. The [discrepancy catalogue](discrepancy-catalogue.md) tracks these classes.
- External-tool agreement is differential evidence, not a compatibility requirement or ground-truth substitute.
- The standalone post-calling mtDNA normalizer currently rejects a source variant whose anchored REF allele itself spans the FASTA/rCRS end-to-start seam; it does not silently rotate or reinterpret that event.
- Production readiness requires approved real-trace validation in addition to engineering test success.

Canonical behavioral boundaries are defined by [requirements](../requirements/README.md), [design](../design/README.md), and [architecture invariants](../architecture/invariants/README.md).
