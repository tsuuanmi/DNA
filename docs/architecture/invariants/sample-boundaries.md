# Read Placement and Sample Boundaries

This is the canonical index for `INV-READ-*` and `INV-SAMPLE-*`.

- [[architecture/invariants/read-placement|Read placement]]: independent placement, evidence-derived orientation/coverage, and no filename-driven pairing.
- [[architecture/invariants/sample-structure|Sample structure and topology]]: identity, sparse loci, overlap, coverage, and normalized-variant support topology.
- [[architecture/invariants/sample-signal|Sample signal and profiles]]: authoritative call-signal projection, profile availability/contribution, aggregation, heterogeneity, and directional geometry.

Invariant IDs remain stable. Other docs should reference the invariant ID rather than restating its normative language.
