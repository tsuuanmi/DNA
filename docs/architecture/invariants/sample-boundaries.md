# Read Placement and Sample Boundaries

This is the canonical index for `INV-READ-*` and `INV-SAMPLE-*`.

- [Read placement](invariants/read-placement.md): independent placement, evidence-derived orientation/coverage, and no filename-driven pairing.
- [Sample structure and topology](invariants/sample-structure.md): identity, sparse loci, overlap, coverage, and normalized-variant support topology.
- [Sample signal and profiles](invariants/sample-signal.md): authoritative call-signal projection, profile availability/contribution, aggregation, heterogeneity, and directional geometry.

Invariant IDs remain stable. Other docs should reference the invariant ID rather than restating its normative language.
