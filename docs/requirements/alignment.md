# Alignment Requirements

**Requirement namespace:** `SRS-ALN-*`

These requirements are part of the canonical [[requirements/SRS|DNA SRS]].

- **SRS-ALN-001:** DNA MUST evaluate retained forward and reverse-complement evidence-profile queries under the affine-gap semi-global Gotoh scoring contract, consuming the complete retained query and allowing free reference flanks. An implementation MAY bypass dynamic-programming evaluation only when it proves the same globally optimal score, orientation/placement ambiguity semantics, and traceback columns under SRS-ALN-013 or SRS-ALN-014.
- **SRS-ALN-002:** Canonical reference substitution scoring MUST use the retained `EvidenceProfile` mass for that reference base as a fixed-point expected match/mismatch score. A missing profile or non-canonical reference base MUST use the configured ambiguous score. A gap of length `k` MUST retain `open + k × extension` semantics in the same fixed-point score scale.
- **SRS-ALN-003:** Traceback MUST use the documented deterministic state and gap-extension tie order. On equal scores the state preference is Match > Deletion > Insertion.
- **SRS-ALN-004:** Circular references MUST align against a doubled sequence, consume at most one reference length, canonicalize modulo coordinates, and expose two segments when crossing origin.
- **SRS-ALN-005:** Both orientations MUST be evaluated internally. JSON MUST report only the selected orientation, callable-base count, callable identity, unresolved-base count, masked-base count, gap-open count, reference segments, callable reference segments (SRS-ALN-015), and origin-wrap flag. Score, gapped rows, operation runs, traceback columns, and redundant match/mismatch counts MUST be omitted; original-call mapping is exposed through each variant's direct `calls` array.
- **SRS-ALN-006:** An exact best profile-score orientation tie, a genuinely distinct equally scoring placement after canonicalization, insufficient callable columns, low identity, over-limit matrix, or invalid traceback MUST fail explicitly. Repeat-equivalent optimal indel placements MUST be canonicalized under `SRS-ALN-012` rather than treated as distinct placement failures. Primary-sequence exact-match/mismatch counts MUST NOT break a profile-score orientation tie. When the selected orientation's two best placements tie, the calls they place at different reference positions (an inserted call at none) are disputed; when every call from one end of the query to the farthest disputed call is unreliable — inside one of the read's unreliable spans (`ReadEvidence::unreliable`, SRS-CALL-024) or masked — DNA MUST leave that stretch unplaced (no alignment column, its evidence and verdicts unchanged) and align the remaining calls again under this contract, once; a tie there, a tie disputing any other call, or no remaining call MUST still fail as a distinct placement ([[ADR-0086]]).
- **SRS-ALN-007:** The selected alignment MUST determine the read's covered reference region from traceback. The default short-reference analysis MUST NOT require or consume an HV/amplicon/expected-region classifier to constrain placement.
- **SRS-ALN-008:** Filename, amplicon/HV label, primer label, declared forward/reverse direction, or other assay metadata MUST NOT change scientific placement for identical AB1, reference, configuration, and method inputs. Such metadata MAY be introduced only as provenance or post-mapping QC unless a separately versioned method explicitly defines otherwise.
- **SRS-ALN-009:** The complete one-read scientific products after selected-alignment interpretation and variant extraction MUST be representable as one `ReadObservation` boundary: a modality-neutral `CalledRead` (input identity, per-read evidence, selected alignment, read-level variants) and the Sanger attachment (calls, signal observations, callability, quality control) that reports join to it (ADR-0069).
- **SRS-ALN-010:** Alignment score arithmetic MUST use a deterministic fixed-point scale of 1024 integer units. Profile support MUST be quantized by `round(weight × 1024)` before DP comparison, and match/mismatch/ambiguous/gap score deltas MUST all use the same scale.
- **SRS-ALN-011:** `callable_columns`, `callable_identity`, unresolved-query count, exact matches, and mismatches MUST remain derived from the retained primary sequence on the selected traceback. Existing callable/identity admission thresholds therefore remain primary-sequence gates after profile-aware placement until separately versioned semantics are adopted.
- **SRS-ALN-012:** Among maximum-score tracebacks that differ only by sequence-equivalent shifting of the same indel through a homopolymer or tandem repeat, DNA MUST emit one canonical reference-oriented alignment. Equivalent gap content SHOULD use the fewest contiguous gap runs, then each gap MUST be placed furthest 3' with respect to the rCRS light strand (right-most in ordinary increasing rCRS coordinates). The maximum score MUST choose the explanation (which calls match, are substituted, inserted, or face a deletion); among the placements of that explanation that keep its primary-base score (each call's profile replaced by its primary base), the 3'-most MUST be taken even when its profile score is lower, so a read's signal purity never decides where a sequence-equivalent gap sits (ADR-0047 §1 amendment). Canonicalization MUST NOT choose another explanation, collapse non-equivalent edit explanations, or shift an indel across the rCRS origin seam; the only exception is the run-structure re-expression of SRS-ALN-016. Variant representation MUST NOT silently undo this canonical alignment without an explicitly separate representation contract.

- **SRS-ALN-013:** A fast alignment path MAY return or reject an alignment without executing full Gotoh only when it proves, from the same fixed-point profile scores and gap penalties, that the per-locus substitution upper bound is attainable and whether that bound has zero, one, or multiple canonical placements in each orientation. Any missing proof precondition, unattained bound in both orientations, unsupported span, or over-limit matrix case MUST fall back to the authoritative Gotoh path so existing errors and scientific semantics are preserved.

- **SRS-ALN-014:** After obtaining any valid alignment-score lower bound `S`, DNA MAY restrict Gotoh evaluation to certified reference windows only when it derives, from the same fixed-point profile and gap scoring contract, a global substitution upper bound `U`, a strictly positive minimum score loss `lambda` for one edit that breaks an exact seed, and an edit budget `E = floor((U - S) / lambda)`. Query loci whose best canonical base does not beat every other canonical base by at least `lambda` (including loci without a profile) are wildcards that no seed may contain. DNA MUST then choose `E + 1 + A` disjoint wildcard-free exact seeds, where `A` is the number of non-canonical symbols one alignment can cover, and every reference occurrence of those seeds that can support a score of at least `S` MUST be covered by the evaluated windows, with window coordinates and canonicalization in whole-reference (doubled circular) coordinates. The same proof MAY establish that an orientation cannot tie or beat a score already proven, or already evaluated by full Gotoh, in the opposite orientation. If seed completeness, arithmetic safety, or an implementation resource bound cannot be established, DNA MUST fall back to the authoritative full-reference Gotoh path.

- **SRS-ALN-015:** The alignment query MUST present every masked call inside the trim interval as an unresolved base without an evidence profile, except a call whose mask anchors the alignment (`Anchoring`), which keeps its call and profile; the Sanger modality marks its `dephased` calls so (SRS-CALL-011). Masked query bases MUST be counted as `masked_bases`, separately from `unresolved_bases`, and the reference segments observed by callable calls — unmasked calls that read a resolved base (A, C, G, or T) — and by deletions between them, MUST be reported in alignment order as `callable_reference_segments`, each inside one mapped reference segment. An unresolved call (`N`) observes no base, whether or not its modality masks it.
- **SRS-ALN-016:** After orientation and placement selection and the admission gates, each maximal block of non-exact-match columns MUST be grown to whole reference runs, run by run, until both sides end at an anchor: an exact canonical match whose base the read's adjacent call inside does not repeat. Growth MUST stop without a change at the alignment end, at the circular origin, or beyond `alignment.max_stretch` reference bases. A stretch whose read calls are all canonical, include a masked call, spell the reference's run bases in order, and change run lengths in one direction only (all longer or all shorter) MUST be rewritten as paired matches plus one length edit at the 3' end of each changed run. The placement, span, score, and every column outside rewritten stretches MUST be kept, and metrics MUST be recomputed from the rewritten columns (ADR-0072).
- **SRS-ALN-017:** On a read whose ends its modality vouches for (a reviewed consensus record, SRS-VAR-015), each deletion MUST be moved 3' across every adjacent unresolved call (`N`) without an evidence profile, and across the repeat-equivalent bases beyond, before run-structure re-expression. Such a call scores the same against every reference base, so it leaves the deletion's place among equally scoring placements undecided; DNA MUST take the 3'-most, as SRS-ALN-012 does for repeats, rather than the traceback's arbitrary one. The move MUST NOT change the score or cross the rCRS origin seam, and it MUST NOT apply to a read whose ends are not vouched, where an unresolved call stands for a masked stretch whose gaps carry no placement.
