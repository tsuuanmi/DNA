# Input and Process Boundary Requirements

**Requirement namespace:** `SRS-IN-*`

These requirements are part of the canonical [DNA SRS](SRS.md).

- **SRS-IN-001:** `analyze` and `basecall` MUST accept exactly one regular non-empty Sanger trace path. `sample` MUST accept one sample identifier and one or more regular non-empty Sanger trace paths. The current supported Sanger encoding is ABIF; filename suffix MUST NOT determine support. Reference-guided commands MUST require one regular non-empty FASTA path; `basecall` MUST NOT accept a reference. Directories, manifest/list compatibility inputs, and globs MUST NOT be accepted by the core CLI.
- **SRS-IN-002:** Supported Sanger trace bytes MUST begin with the `ABIF` signature; every directory count, size, product, offset, inline payload, and allocation MUST be checked before use.
- **SRS-IN-003:** Canonical decode MUST require `DATA.9-12`, `FWO_.1`, and `PLOC.2`; FWO MUST be an exact A/C/G/T permutation; channels MUST be equally sized; PLOC MUST be strictly increasing and in range.
- **SRS-IN-004:** `PLOC.2` is required; `PBAS.2` and `PCON.2` MAY be consumed as optional vendor evidence. `P2BA.1` MUST be ignored. Uppercase IUPAC vendor bases and the ABIF one-byte byte/char PCON representations MUST be accepted. No alternate-tag fallback is permitted.
- **SRS-IN-008:** Optional PBAS/PCON cardinality MUST NOT define or extend the scientific locus series. A present vendor series whose decoded length differs from the valid PLOC count MUST remain non-fatal trace-integrity evidence; DNA MUST process exactly the PLOC-defined loci and boundedly ignore unavailable/excess vendor positions.
- **SRS-IN-005:** A reference-guided `analyze` or `sample` FASTA MUST contain exactly one non-empty A/C/G/T/N record no longer than 50,000 bases. `basecall` MUST perform no FASTA I/O.
- **SRS-IN-006:** Empty, missing, malformed, unsupported, over-limit, or unreadable input MUST return a typed error without panic or result file.
- **SRS-IN-007:** Generic ABIF directory parsing MUST follow the container specification rather than imposing scientific-tag assumptions globally. A directory item MUST contain at least its logical `element_size × element_count` payload; a larger `data_size` that is permitted by ABIF padding/reserved-space behavior MUST NOT by itself make the file invalid. Decoders for required scientific tags MAY impose stricter tag-specific type, element-size, cardinality, and semantic constraints.
- **SRS-IN-010:** The single-read reference-guided command MUST be `signal analyze <trace> --reference <reference.fasta>` and derive `results/<trace-stem>.json`. The reference-free command MUST be `signal basecall <trace>` and derive `results/<trace-stem>.basecalls.json`. The sample command MUST be `signal sample <sample-id> <trace>... --reference <reference.fasta>` and derive `results/<sample-id>.sample.json`. The core-only command MUST be `signal call <sample-id> <sequences.fasta>... --reference <reference.fasta>` and derive `results/<sample-id>.variants.json`. The post-calling command MUST be `signal notation <sample-id> <variants.json> --reference <reference.fasta>` and derive `results/<sample-id>.notation.json`. Conventional `.ab1` filenames remain valid examples, but the suffix is not a format discriminator. No output-path or format compatibility option is permitted.
- **SRS-IN-013:** `call` MUST accept one sample identifier and one or more regular non-empty FASTA files of reviewed consensus sequences, each file at most 1 MiB, with at most 64 records in total. Every record is one read: its identifier MUST be non-empty and unique within the call, its sequence MUST contain 1 to 50,000 symbols, each a base, an IUPAC ambiguity code, or `N` (case-insensitive, whitespace ignored), and no two records may share a sequence. It MUST use the same reference rules as `sample` (SRS-IN-005).
- **SRS-IN-014:** `notation` MUST accept one sample identifier and one regular non-empty `dna.variants/v1` document of at most 16 MiB whose `sample_id` is that identifier and whose reference SHA-256 is the supplied reference's. Its variants MUST have a known kind and non-empty A/C/G/T alleles. The configured target profile MUST declare notation.
- **SRS-IN-011:** Help/version MUST succeed without reading analysis inputs.
- **SRS-IN-012:** Invalid CLI arguments MUST produce concise stderr and nonzero status.
