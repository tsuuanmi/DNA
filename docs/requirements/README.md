# Requirements

This directory contains **normative current requirements**: what DNA must, should, or may do.

Start with [SRS.md](SRS.md). Requirement families remain split by stable domain boundary so the specification is navigable without duplicating requirements.

- [SRS index](SRS.md)
- [Quality attributes](quality-attributes.md)
- [System constraints](constraints.md)
- [Validation acceptance criteria](../validation/acceptance-criteria.md)

Requirements define intended behavior. Mechanism belongs in [design](../design/README.md), rationale in [decisions](../decisions/README.md), exact public shapes in [reference](../reference/README.md), and verification evidence in [validation](../validation/README.md).
