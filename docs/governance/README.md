# Governance

external-reference evidence evolve without confusing current truth with history or
exploration.

  repository-agnostic specification of the knowledge system; hand this file alone
  to adopt it elsewhere.
- [DNA documentation policy](documentation.md): DNA's profile of the standard,
  its commands, and its CI rules.
- [Retired documents ledger](retired.md): documents removed from the tree, with
  the commit that holds their full text.
- [Versioning](versioning.md)
- [Repository governance](repository.md)
- [Data and fixture policy](data.md)
- [Reference validation](reference-validation.md)
