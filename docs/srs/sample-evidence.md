# Sample Evidence Requirements

**Requirement namespace:** `SRS-SAMPLE-*`

These requirements are part of the canonical [DNA SRS](README.md).

- **SRS-SAMPLE-001:** Multi-read sample analysis MUST process every trace independently through the same authoritative read-observation path used by single-read analysis before cross-read reconciliation.
- **SRS-SAMPLE-002:** Cross-read overlap and support MUST be discovered from mapped reference coordinates/variants rather than inferred from canonical F/R pair names.
- **SRS-SAMPLE-003:** A usable read MUST NOT be rejected solely because a nominal F/R partner is missing.
- **SRS-SAMPLE-004:** Sample evidence MUST contain one deterministic read registry sorted by input SHA-256. Reviewer-facing filename-stem provenance, stable SHA-256 identity, trace-integrity evidence, derived orientation, and mapped post-trim coverage MUST be defined once per read; locus and variant evidence MUST reference that registry by unique reviewer-facing read name. Filename, amplicon, primer, or replicate grouping MUST NOT be treated as a scientific placement or exclusive merge key. Duplicate trace content MUST NOT contribute twice.
- **SRS-SAMPLE-005:** Sample evidence MUST serialize locus observations only at positions where at least one covering read is alternate, unresolved, or deleted. Every covering read at such a differential locus MUST remain explicit, including canonical reference support with its observed base and quality. For a read, a position inside its mapped reference segments but absent from `locus_differences[]` is a canonical reference match; a position outside its mapped segments is uncovered. Missing coverage MUST NOT become reference support.
- **SRS-SAMPLE-006:** Normalized variant support MUST retain the contributing read name, configured eligibility, exact exclusion reasons, and reviewer-facing reference-oriented base/peak/quality evidence; read-level filtering MUST NOT erase an observed normalized variant. Future sample variants and discordance states MUST derive from this evidence; a consensus sequence MAY be emitted only as a downstream projection.
- **SRS-SAMPLE-007:** After deterministic SHA-256 read ordering, sample reconciliation MUST discover an unordered read-pair overlap only from shared mapped reference coordinates. A pair with no shared coordinate MUST produce no overlap edge, and lack of an overlapping or canonical F/R partner MUST NOT reject an otherwise valid read.
- **SRS-SAMPLE-008:** Pairwise overlap evidence MUST distinguish all shared reference positions from comparable nucleotide positions. Only coordinates where both reads have canonical A/C/G/T query bases MAY enter the nucleotide agreement denominator; unresolved symbols and deletions MUST remain outside that denominator, and indel/gap evidence MUST remain in its dedicated locus/variant evidence rather than receive fabricated nucleotide agreement.
- **SRS-SAMPLE-009:** A materialized overlap pair MUST be eligible for later consensus reconciliation exactly when its comparable canonical-base count is at least `minimum_comparable_bases` and its canonical-base agreement fraction is at least `minimum_overlap_agreement`. Failed rules MUST remain explicit as `comparable_bases_below_minimum` and/or `agreement_below_minimum` without mutating either read.
- **SRS-SAMPLE-010:** Compact sample evidence MUST expose pairwise overlap/admission evidence in addition to the existing read registry, sparse differential loci, and normalized variant support. This evidence MUST NOT itself produce a consensus sequence, sample-level variant verdict, majority vote, genotype, heteroplasmy estimate, or reference vote.
- **SRS-SAMPLE-011:** Sample evidence MUST expose a run-length encoded reference-coordinate coverage topology derived only from selected post-trim read segments. Each maximal interval MUST report total read depth plus forward/reverse orientation depth, with total depth equal to the orientation-depth sum. Coverage MUST include every independently placed read regardless of pairwise overlap eligibility and MUST NOT imply canonical-base agreement, consensus admission, or biological strand independence.
- **SRS-SAMPLE-012:** Every normalized sample variant MUST retain a factorized support topology derived from its authoritative per-read support records and selected read orientations: total observing reads, eligible observing reads, forward/reverse observing reads, and eligible forward/reverse observing reads. Each read MUST contribute at most once to one normalized variant identity. The topology MUST include ineligible observations, MUST NOT count covering reference/unresolved/competing-event reads as support for the variant, and MUST NOT be interpreted as confidence, vote weight, sample-level verdict, or biological strand independence.
- **SRS-SAMPLE-013:** Sample aggregation MUST preserve the existing basecall-independent `EvidenceProfile` for every call-backed differential-locus observation and variant-associated call by matching original call index to `LocusEvidence`, then projecting A/C/G/T weights into the selected reference orientation. A valid zero-signal locus with no profile MUST remain absent; DNA MUST NOT synthesize a called-base, uniform, or reference-derived fallback. Deletion observations MUST have no nucleotide profile. Public differential-locus projection is governed by `SRS-SAMPLE-023`; profile evidence MUST NOT change placement, read/variant eligibility, or produce consensus by itself.
- **SRS-SAMPLE-014:** Every retained differential locus MUST derive factorized support topology from its authoritative observations and selected read orientations: total reads, forward/reverse reads, and reference/alternate/unresolved/deletion reads. The orientation counts and state counts MUST each sum to total reads. The topology MUST NOT treat missing coverage as reference support and MUST NOT imply weighting, confidence, consensus, or biological strand independence.
- **SRS-SAMPLE-015:** Sample aggregation MUST preserve whether each call-backed differential-locus observation and each variant-associated call falls inside an existing merged candidate-noisy call region from `dna.windowed_snr/v1`. Deletions MUST preserve this call-specific context as absent rather than fabricated. Sample reconciliation MUST NOT recompute SNR or use noisy-region membership as read admission, local contribution eligibility, variant filtering, consensus weight, confidence, or artifact classification.
- **SRS-SAMPLE-016:** Every call-backed sample observation MUST resolve one authoritative `LocusEvidence` by matching original call index and preserve its baseline-corrected A/C/G/T amplitudes, per-channel SNR, optional `EvidenceProfile`, and merged noisy-region membership in one reference-oriented `CallDNAEvidence`. Reverse reads MUST reorder all A/C/G/T channel-valued evidence consistently. Deletions MUST have no fabricated call signal evidence. These internal quantitative observations MUST NOT by themselves define contributor eligibility, consensus weight, calibrated confidence, or artifact classification.
- **SRS-SAMPLE-017:** Every retained differential locus MUST expose the number of observations with an available basecall-independent nucleotide profile and factor that count by selected forward/reverse orientation. Profile-available count MUST equal the sum of profile-forward/profile-reverse counts and MUST NOT exceed non-deletion read count. Unresolved calls MAY count when a valid profile exists; zero-signal missing profiles and deletions MUST NOT. Profile availability MUST NOT be interpreted as contributor eligibility, agreement, weight, confidence, or a consensus vote.
- **SRS-SAMPLE-018:** Every retained differential-locus observation MUST have an explicit structural nucleotide-contribution state. A call-backed observation with a present basecall-independent profile MUST be `Eligible`, including unresolved calls and calls inside candidate-noisy regions. A call-backed observation without a profile MUST be `MissingProfile`; a deletion MUST be `DeletionEvent` and remain on the separate gap/event path. This first contributor policy MUST NOT use relative quality, SNR, noisy-region membership, variant eligibility, or any new threshold as a rejection or weighting rule.
- **SRS-SAMPLE-019:** Every retained differential locus MUST accumulate reference-oriented A/C/G/T `EvidenceProfile` vectors from `Eligible` observations using unit read mass, retaining total plus forward-only and reverse-only support vectors and contributor counts. Total contributors MUST equal forward plus reverse contributors, and total support MUST be the channel-wise sum of the orientation partitions. Missing-profile observations and deletion events MUST contribute no nucleotide mass. This accumulator MUST NOT use amplitude, SNR, relative quality, noisy-region state, or alignment score as a weight and MUST NOT normalize or select a consensus base.
- **SRS-SAMPLE-020:** Each non-empty total/forward/reverse unit-mass nucleotide-support partition MUST derive an arithmetic mean A/C/G/T evidence profile by dividing channel support by that partition's contributor count; empty partitions MUST have no mean profile. Mean profiles MUST preserve contributor counts and MUST NOT select a nucleotide, classify agreement/discordance, assign confidence, or introduce quality/SNR/artifact weighting.
- **SRS-SAMPLE-021:** Every non-empty total/forward/reverse eligible-profile partition MUST retain threshold-free heterogeneity geometry: mean within-profile Gini impurity, between-profile dispersion, and total mean-profile heterogeneity, with total heterogeneity equal to within impurity plus between dispersion within numerical tolerance. These metrics MUST NOT be interpreted as biological mixture, heteroplasmy, confidence, or a categorical consensus state.
- **SRS-SAMPLE-022:** When both forward and reverse mean nucleotide profiles exist, DNA MUST retain their Total Variation distance in [0, 1]; otherwise the directional distance MUST be absent. This distance MUST remain a descriptive orientation-profile metric and MUST NOT introduce a discordance threshold, strand-bias verdict, confidence value, or consensus decision.
- **SRS-SAMPLE-023:** Public sample differential-locus evidence MUST project the existing factorized support topology and, for each call-backed observation, the existing candidate-noisy-region membership plus optional normalized reference-oriented A/C/G/T `EvidenceProfile`. A call-backed observation with no real profile MUST omit `profile`; a deletion MUST omit both `profile` and `in_noisy_region`. The report layer MUST NOT recompute signal evidence, fabricate missing profiles, expose corrected amplitudes/SNR, or interpret topology/profile/noise as a consensus, confidence value, artifact label, or biological independence claim.
